A short, funny rant about an everyday annoyance, written by a deterministic program, for the make.fun bounty: https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046

Why this rant: it is aimed at one machine doing one thing — the password system that demands a reset, accepts it, then demands it again. The rant earns its anger by walking the loop step by step (reset, confirm, log in) instead of announcing a mood, and the joke arrives only in the final clause, where the speaker stops fighting the system and starts envying monks. Every sentence is load-bearing: cut any of the three repeated actions and the loop stops feeling inescapable; add anything after the monks and the punch goes soft.

`main.ts` writes the rant to the output directory with no trailing newline, no network, no randomness, and no clock reads, so repeated runs produce byte-identical output.
